Chrome download failed or stuck? How to resume it

A big download that dies halfway, with “Failed – Network error”, a stall, or no Resume button, is usually a dropped connection or a server that gave up. Here’s how to get the file without starting over.

Try these first

Each takes under a minute, and they fix most stuck downloads.

  1. Click Resume. Press Ctrl+J to open Chrome’s download list and look for a Resume button on the failed file. It only works if the server allows resuming, and the link hasn’t expired.
  2. Check your connection. A brief drop, or switching between Wi-Fi and a cable or hotspot mid-download, is enough to break a large file. Reconnect, then resume.
  3. Check disk space and the folder. A full drive, or a save folder Chrome can’t write to, makes downloads fail.
  4. Look at your antivirus or firewall. Security software sometimes blocks a download midway. Turn it off briefly to test, and turn it back on afterwards.
  5. Get a fresh link. Many sites give links that expire. Go back to the page and start the download again.

Chrome’s own help page explains each message: Fix file download errors.

What the error usually means

Chrome saysWhat’s usually going on
Failed – Network errorThe connection was cut before the file finished. Resume, or retry on a steadier connection.
Failed – ForbiddenThe server refused the request: a link that expired, a page that must be open first, or too many connections from you at once.
Failed – No fileThe file is gone from the server, or the link has expired.
Failed – BlockedSecurity software or Chrome’s safe-browsing check stopped it.

When Chrome can’t resume it: use a download manager

Chrome downloads a file over a single connection, and if that connection dies it often can’t pick up again. A download manager is built for this, because it keeps track of exactly which bytes it already has.

Here is what Vantload does in the situations above:

  • The connection drops: it reconnects automatically and continues from the exact byte where it stopped, rather than starting again.
  • A connection goes silent: after 30 seconds without data it assumes the connection is stuck and reconnects.
  • The server only allows a few connections: when it answers extra connections with a 403 “Forbidden”, Vantload quietly uses fewer instead of failing.
  • The server says it can resume but can’t: it falls back to an ordinary single download instead of giving up.
  • The link needs the page that held it: links sent from Chrome carry that page along, so servers that check it accept the request.
  • You quit or restart: pause now, resume later, even after restarting the app, as long as the server allows resuming.

How to hand a failed download to Vantload

  1. Install Vantload and add the Chrome extension.
  2. Click the download link again. The extension passes it to Vantload, which asks you to confirm and then starts.
  3. No extension yet? Copy the link and paste it into Add URL in Vantload.

What no tool can fix

If the file has been removed, the link has expired, or the site requires you to be signed in, no download manager can recover it. Vantload also can’t continue a partly downloaded file from the middle when the server doesn’t support resuming at all. In that case it downloads the file in one piece.
